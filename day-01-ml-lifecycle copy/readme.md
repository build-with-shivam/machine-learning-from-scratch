# 🚀 Lesson 01 - Machine Learning Lifecycle

## Objective

Before building any Machine Learning model, it's important to understand the complete lifecycle.

Every ML project follows a structured workflow:

1. Collect Data
2. Clean Data
3. Define the Problem
4. Train/Test Split
5. Choose an Algorithm
6. Train the Model
7. Make Predictions
8. Evaluate Performance
9. Deploy & Monitor

This lesson introduces these stages without diving into algorithms or code complexity.

The goal is to build a strong foundation before moving to real-world projects.
